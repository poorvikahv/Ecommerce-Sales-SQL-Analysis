# E-commerce Sales and Customer Behaviour Analysis Using SQL

## Project Overview

This project analyses the Brazilian E-Commerce Public Dataset by Olist using Microsoft SQL Server. The objective is to explore sales performance, customer purchasing behaviour, product performance, and business trends using SQL.

## Project Objectives

- Analyse overall sales and revenue performance.
- Identify repeat customers and high-value customers.
- Find best-selling products and revenue-generating categories.
- Analyse monthly and yearly sales trends.
- Evaluate seller performance, payment methods, and delivery performance.

## Tools and Technologies

- Microsoft SQL Server 2022 Express
- SQL Server Management Studio (SSMS)
- SQL
- Git and GitHub

## Dataset

**Source:** [Brazilian E-Commerce Public Dataset by Olist – Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

The dataset contains information about orders, customers, products, sellers, payments, reviews, and delivery.

## Analysis Modules

1. **Basic Business Analysis** – Overall orders, revenue, payment methods, and delivery performance.
2. **Customer Analysis** – Customer spending, repeat purchases, customer segmentation, and state-wise analysis.
3. **Product Analysis** – Product sales, category performance, seller revenue, and product reviews.
4. **Sales Trend Analysis** – Monthly, quarterly, and yearly revenue trends, growth rates, and moving averages.
5. **Intermediate SQL Analysis** – Customer rankings, seller rankings, revenue contributions, and purchasing frequency.

## SQL Concepts Used

- SELECT, WHERE, ORDER BY

- INNER JOIN and LEFT JOIN
- Subqueries and Common Table Expressions (CTEs)
- CASE WHEN statements
- Window functions: ROW_NUMBER, RANK, DENSE_RANK, LAG
